# AuraLe Assets Directory

이 폴더는 AuraLe 카세트 플레이어의 그래픽 및 사운드 에셋을 보관하는 폴더입니다.

## 주요 에셋 파일 규격 가이드

### 1. `reel.png` (카세트 회전 휠/릴)
- **용도**: 재생 시 회전하는 좌/우 카세트 릴 그래픽
- **권장 규격**: 
  - 포맷: **투명 배경 PNG** (Alpha 채널 포함)
  - 크기: 정사각형 (예: 128x128, 256x256, 512x512)
  - 특징: 중심축 구멍과 외곽이 투명하게 처리되어 있어야 카세트 섀시와 자연스럽게 결합됩니다.

### 2. `background.png` / `background.jpg` (기본 배경)
- **용도**: 앱 실행 시 카세트 투명 창에 표시될 기본 배경/캐릭터 일러스트
- **권장 비율**: 약 16:9 ~ 21:9 와이드 비율 (가로 1200px 이상 권장)

### 3. `app_icon.ico` (프로그램 아이콘)
- **용도**: 타이틀바 및 실행 파일 아이콘
